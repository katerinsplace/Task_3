# Проект автоматизации тестирования сервиса Stellar Burgers

Данный проект содержит автоматизированные тесты для веб-интерфейса (UI) и программного интерфейса (API) учебного стенда [Stellar Burgers](https://qa-education-services.ru).

## 🛠 Технологический стек
* **Язык программирования:** Python 3.10+
* **Тестовый фреймворк:** Pytest
* **UI Автоматизация:** Selenium WebDriver (с использованием паттерна Page Object Model)
* **API Автоматизация:** Requests
* **Отчетность:** Allure Report

---

## 🚀 Инструкция по запуску

### 1. Подготовка окружения
Клонируйте репозиторий и установите необходимые зависимости:
```bash
# Установка библиотек из файла зависимостей
pip install -r requirements.txt
```

### 2. Запуск тестов
Вы можете запускать тесты как локально, так и с генерацией Allure-отчетов.

* **Запуск всех тестов:**
  ```bash
  pytest
  ```

* **Запуск конкретного файла тестов:**
  ```bash
  pytest tests/test_create_order.py
  ```

* **Запуск тестов сбором результатов для Allure:**
  ```bash
  pytest --alluredir=allure-results
  ```

### 3. Просмотр отчетов Allure
Для генерации и открытия красивого HTML-отчета в браузере выполните (требуется установленный Allure CLI):
```bash
allure serve allure-results
```

## 💡 Особенности реализации
1. **Предусловия через API:** Для UI-тестов, требующих авторизованного пользователя, создание аккаунта и получение токенов происходит быстро через API-запросы в фикстуре `create_user`, что экономит время выполнения.
2. **Стабильность UI:** Действия с элементами (клик, drag-and-drop) обернуты в явные ожидания `WebDriverWait` и используют цепочки действий `ActionChains` для минимизации мигающих (flaky) тестов.
